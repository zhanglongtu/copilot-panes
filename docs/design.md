# 界面的视觉规则：亮度表示死活，选中行铺底色，内容区是半框

这份文档讲 copilot-panes 的界面怎么画、为什么这样画，给改界面的人看。读完应该知道每种状态该用什么颜色、什么符号、什么粗细，改样式时哪些规则不能破坏。样式的代码在 `src/ui/views/` 和 `src/ui/theme.ts`；快照测试逐项断言这里的表。

## 原则

一个 session 常有二三十个条目，绝大多数已经结束，只有一两个在跑。所以界面要让在跑的突出，让结束的退到背景里：

- **亮度表示死活。** 在跑的最亮，做完一轮在等的暗一档，结束的最暗。色相只表示种类：子 agent 是藤紫，命令是青。只有活着的条目才带色相。
- **选中的名单行整行铺底色。** 这是全屏唯一的底色条。
- **内容区是半框。** 上边是带标题的横线，左边是竖线，右边和下边不封口。名单和内容区靠它分开，也靠它的颜色和粗细说明键盘输入发给谁、焦点在哪。
- **顶行只说“哪个 session、多少在跑”。** 异常单独占第二行，写明原因和怎么恢复。模式开关放在底部按键提示里，写成“按这个键会做什么”。
- **粗体只用于**：在跑的条目的名字、选中行的名字、标题行里的名字、你自己发的消息、顶行的目录名。

## 颜色

颜色用 xterm 256 色编号，不用真彩色，因为 tmux 里的 `COLORTERM` 常常是空的。代码里用 `src/ui/theme.ts` 的语义名，由主题换成编号。

| 语义名 | 深色 | 浅色 | 用在哪 |
| --- | --- | --- | --- |
| `violet` 藤紫·亮 | 141 | 56 | 在跑的子 agent、焦点所在的半框、选中行的色块 |
| `violetDim` 藤紫·暗 | 134 | 97 | 等你发话的符号、焦点不在时的半框 |
| `cyan` 青·亮 | 80 | 23 | 在跑的命令、进度条、焦点所在的半框、选中行的色块 |
| `cyanDim` 青·暗 | 66 | 30 | 焦点不在时的半框 |
| `orange` 橙 | 215 | 130 | 未读的点、第二行的异常提示 |
| `red` 红·亮 | 210 | 124 | 未读的失败 |
| `redDim` 红·暗 | 167 | 131 | 已读的失败 |
| 一档文字 | 默认前景 | 默认前景 | 活着的条目、内容区正文 |
| `text2` 二档 | 250 | 238 | 等你发话的条目、按键名 |
| `grey` 三档 | 244 | 243 | 已结束的、模型、次要信息、按键说明 |
| `selFocus` | 237 | 252 | 选中行底色，焦点在名单 |
| `selBlur` | 236 | 254 | 选中行底色，焦点在内容区 |

每个文字颜色在默认背景（深色按 `#1C1F26`、浅色按 `#FAFAFA` 估）和选中行底色上，对比度都不低于 4.0:1。深色主题里 `violetDim`、`redDim`、`red` 取 134、167、210，浅色主题里 `violet`、`violetDim`、`cyanDim`、`red` 取 56、97、30、124，都是为了达到这个对比度而从相邻编号里挑的。快照测试对每一帧里的每个文字检查对比度。

主题选择：`--light` 或 `--dark` 优先，其次环境变量 `COPILOT_PANES_THEME`，再向终端查背景色（OSC 11，带超时），再看 `COLORFGBG`，都没有用深色。

## 名单每一行的样式

| 状态 | 符号 | 名字 | 模型、用时、token | 最近一步 |
| --- | --- | --- | --- | --- |
| 在跑 | 转动的点，种类色·亮 | 粗体，种类色·亮 | 用时一档，其余三档 | 一档 |
| 等你发话，未读 | `○` 种类色·亮，行首橙色 `•` | 一档 | 二档 | 二档 |
| 等你发话，已读 | `○` 种类色·暗 | 二档 | 三档 | 三档 |
| 失败，未读 | `✗` 红·亮，行首橙色 `•` | 二档 | 三档 | 二档 |
| 失败，已读 | `✗` 红·暗 | 三档 | 三档 | 三档 |
| 已结束、已取消、已停 | `✓`、`⊘`、`◌`，三档 | 三档 | 三档 | 三档 |

- 未读，指条目结束或开始等你发话之后，你还没把它选中过。
- 在跑的命令认出进度、pane 不窄于 80 列时，最近一步先画 10 格进度条（`▰▱`，青·亮）再写数字。
- 选中的行从第 0 列铺到最右一列的底色，第 0 列画 `▌`（种类色·亮），名字粗体，文字提一档：三档变二档，二档变一档，暗色符号变亮。
- pane 窄于 60 列时名单去掉模型列，窄于 48 列时再去掉 token 列；矮于 20 行时名单收成一行。

## 内容区的半框

- 名单下面直接是标题行，它同时是分隔线。焦点在内容区：`┏━ 标题 ━━━` 和每行行首的 `┃`，种类色·亮。焦点在名单：`┌─ 标题 ───` 和 `│`，种类色·暗。
- 标题：子 agent 是 `<名字>  <简述>  <模型>  <状态> <用时>`，命令是 `$ <命令名>  <状态> <用时>`，结束的命令写退出码，如 `失败（退出码 1）`。放不下时先去模型，再去简述，最后截断名字。
- 输入行上面有一条细线，`┠───`（焦点在内容区）或 `├───`，都用种类色·暗。
- 放大（`z`）时名单一行都不显示，标题行紧接顶行，线的末尾写 `第 2 个，共 7 个`。
